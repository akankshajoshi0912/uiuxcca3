Project Overview
SwiftBasket is a high-fidelity grocery shopping prototype designed as part of the User Interface and User Experience Design (UI/UX) CCA3 assignment. It is inspired by Swiggy Instamart and focuses on making online grocery shopping simple, clear, and user-friendly.


Objectives
•	Evaluate the usability of the original Swiggy Instamart interface.
•	Design and test an improved grocery shopping prototype.
•	Identify usability issues through Think Aloud testing.
•	Compare both interfaces and suggest improvements based on user feedback.


Tools Used
•	Figma — UI design and prototyping
•	Google Forms — User feedback collection
•	Speech-to-text transcription — Usability session transcripts
•	GitHub — Project documentation and submission



Usability Testing Method
Five participants were asked to complete a grocery-shopping task on both interfaces.
Task: Find bread, add it to the cart, review the order, and proceed towards checkout. Participants also explored order tracking where available.

During testing, participants were encouraged to think aloud and share their thoughts, expectations, and difficulties while interacting with each interface.




Evaluation Criteria
•	Ease of navigation
•	Product search and discovery
•	Visual hierarchy and readability
•	Cart and checkout usability
•	Clarity of buttons and instructions
•	Overall user experience


Findings and Conclusion
The usability sessions and survey responses will be analysed to compare the original interface with the SwiftBasket prototype. The final report will summarise the key usability issues, participant feedback, and possible design improvements.
